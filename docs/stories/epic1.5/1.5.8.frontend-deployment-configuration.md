# Story 1.5.8: 前端部署与域名配置

## Status
Ready

## 你的目标
将前端应用部署到GitHub Pages，配置生产环境，确保用户能通过HTTPS访问应用。

## 你需要做的关键操作

### 🔧 GitHub Pages配置（你必须亲自完成）
- [ ] **启用GitHub Pages**
  1. 访问GitHub repository设置
  2. 进入Settings > Pages
  3. Source选择"GitHub Actions"
  4. 保存设置

- [ ] **配置生产环境变量**
  在GitHub repository中设置Variables：
  ```
  VITE_GITHUB_CLIENT_ID=你的GitHub OAuth Client ID
  VITE_API_BASE_URL=你的AWS后端API地址
  VITE_GITHUB_REDIRECT_URI=https://your-username.github.io/repository-name/auth/callback
  ```

### 🚀 前端部署执行（你亲自操作）
- [ ] **触发部署**
  ```bash
  # 提交代码到main分支触发自动部署
  git add .
  git commit -m "feat: configure production deployment"
  git push origin main
  ```

- [ ] **监控部署过程**
  - 访问GitHub Actions页面
  - 查看前端部署工作流执行状态
  - 确认构建和部署步骤都成功

- [ ] **验证部署结果**
  - 访问GitHub Pages URL：`https://your-username.github.io/repository-name`
  - 确认前端应用正常加载
  - 检查浏览器控制台无错误

### 🧪 生产环境功能测试（你亲自验证）
- [ ] **测试GitHub OAuth登录**
  1. 在GitHub OAuth App设置中添加生产回调URL
  2. 在前端点击GitHub登录按钮
  3. 验证跳转到GitHub授权页面
  4. 授权后确认回跳到应用并显示用户信息

- [ ] **测试前后端集成**
  - 确认前端能调用AWS后端API
  - 验证没有CORS跨域错误
  - 测试数据录入和查询功能
  - 确认所有功能正常工作

### 🌐 自定义域名配置（可选）
- [ ] **配置DNS记录**（如有域名）
  ```dns
  # CNAME记录
  www.your-domain.com -> your-username.github.io

  # A记录（GitHub Pages IP）
  your-domain.com -> 185.199.108.153
  ```

- [ ] **在GitHub Pages中添加域名**
  - 在Settings > Pages中添加Custom domain
  - 等待DNS验证完成
  - 启用"Enforce HTTPS"

## 技术背景信息

### 部署架构
- **托管平台**: GitHub Pages (免费HTTPS)
- **构建工具**: Vite (React应用构建)
- **部署方式**: GitHub Actions自动部署
- **域名**: github.io或自定义域名

### 环境变量配置
生产环境需要的变量：
- VITE_GITHUB_CLIENT_ID: GitHub OAuth应用ID
- VITE_API_BASE_URL: AWS后端API地址
- VITE_GITHUB_REDIRECT_URI: 生产环境回调URL

### GitHub OAuth配置更新
需要在GitHub OAuth App中添加：
- Homepage URL: https://your-username.github.io/repository-name
- Callback URL: https://your-username.github.io/repository-name/auth/callback

### 常见问题排查
如遇到问题，可向dev agent询问：
- 构建失败：检查package.json和构建脚本
- 部署失败：检查GitHub Actions配置
- OAuth失败：检查回调URL配置
