## 你的目标

## 你需要做的关键操作

### 🔍 前置条件检查
- [ ] **确认Docker环境运行**：Story 1.5.2已完成，所有容器正常运行
- [ ] **验证PostgreSQL服务**：
  ```bash
  docker-compose ps postgres  # 确认状态为Up
  docker-compose logs postgres  # 检查无错误
  ```

### 🗃️ 数据库连接验证（你亲自测试）
- [ ] **测试数据库连接**
  ```bash
  docker exec -it <postgres-container> psql -U postgres
  \l  # 查看数据库列表
  \c livin_matrix_dev  # 连接项目数据库
  \dt  # 查看表列表（初始为空）
  \q  # 退出
  ```

### 🔄 数据库迁移执行（你亲自执行）
- [ ] **运行数据库迁移**
  ```bash
  cd backend
  python -m alembic upgrade head  # 创建所有表
  ```

- [ ] **验证表结构创建**
  ```bash
  docker exec -it <postgres-container> psql -U postgres -d livin_matrix_dev -c "\dt"
  # 应该看到：users, user_daily_records, workout_sessions, token_blacklist
  ```

### 🧪 数据完整性测试（你亲自验证）
- [ ] **测试基础数据操作**
  ```sql
  -- 在psql中测试
  INSERT INTO users (github_user_id, github_username, email) 
  VALUES (123456, 'testuser', 'test@example.com');
  
  SELECT * FROM users;  -- 确认数据插入成功
  
  DELETE FROM users WHERE github_user_id = 123456;  -- 清理测试数据
  ```

## 技术背景信息

### 核心数据表
- **users**: GitHub OAuth用户信息
- **user_daily_records**: 6维度日常健康数据
- **workout_sessions**: 运动记录详情
- **token_blacklist**: JWT令牌撤销管理

### 数据库配置
- **连接**: `postgresql://postgres:your_secure_password@localhost:5432/livin_matrix_dev`
- **迁移工具**: Alembic
- **字符编码**: UTF-8
- **时区**: UTC

### 常见问题排查
如遇到问题，可向dev agent询问：
- 迁移错误：`python -m alembic current` 查看当前版本
- 表结构问题：`\d table_name` 查看表定义
- 连接问题：检查DATABASE_URL环境变量
