## 实际执行记录

### 遇到的问题与解决方案

#### 1. 缺失 auth_service.py 模块
**问题**: 后端启动失败，报错 `ModuleNotFoundError: No module named 'app.services.auth_service'`

**解决方案**:
- 创建了基于GitHub OAuth的 `auth_service.py` 文件
- 实现了兼容性方法以适配现有测试代码
- 提供了 `get_or_create_user` 和 `get_user_by_auth0_id` 等关键方法

#### 2. 前端TypeScript错误
**问题**: `useAuth` 函数未导出，导致前端编译失败

**解决方案**:
- 在 `AuthContext.tsx` 中添加了 `useAuth` hook导出
- 修复了 `LoginPage.tsx` 中的状态访问方式

#### 3. Node.js版本兼容性问题
**问题**: Vite 7.0.4与Node.js 18存在 `crypto.hash is not a function` 错误

**解决方案**:
- 将前端Dockerfile的基础镜像从 `node:18-alpine` 升级到 `node:20-alpine`

#### 4. 端口配置冲突
**问题**:
- Vite配置端口3000，但容器内部应该运行在5173
- Docker映射配置为 3000:5173

**解决方案**:
- 修改 `vite.config.ts` 中的服务器端口从3000改为5173
- 确保端口映射正确工作

#### 5. 端口占用冲突
**问题**: 本地Node.js进程占用3000端口

**解决方案**:
- 使用 `lsof -i :3000` 识别占用进程
- 终止冲突进程后重新启动Docker服务
