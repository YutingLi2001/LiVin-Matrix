# Story 1.5.2: Docker本地开发环境建立

## Status
Ready

## 你的目标
建立Docker本地开发环境，让所有服务能在容器中正常运行，为后续开发提供稳定基础。

## 你需要做的关键操作

### 🔧 环境准备（你必须亲自完成）
- [ ] **安装Docker Desktop for Mac**
  - 从官网下载并安装Docker Desktop
  - 启动应用并完成初始设置
  - 配置资源：内存至少4GB，存储至少20GB
  
- [ ] **验证Docker安装**
  ```bash
  docker --version  # 应显示 ≥ 20.10
  docker-compose --version  # 应显示 ≥ 2.0
  docker run hello-world  # 测试基本功能
  ```

### 🚀 服务启动（你亲自执行）
- [ ] **启动所有Docker服务**
  ```bash
  cd /Users/yutingli/Projects/LiVin-Matrix
  docker-compose up -d
  ```

- [ ] **验证服务状态**
  ```bash
  docker-compose ps  # 所有服务应显示Up状态
  ```

### 🧪 功能验证（你亲自测试）
- [ ] **测试数据库连接**
  ```bash
  docker exec -it <postgres-container> psql -U postgres
  ```

- [ ] **测试Redis连接**
  ```bash
  redis-cli -h localhost ping  # 应返回PONG
  ```

- [ ] **访问应用**
  - 前端：http://localhost:3000
  - 后端API文档：http://localhost:8000/docs

## 与Dev Agent的协作

### 何时询问Agent
- Docker Compose文件需要修改时
- 容器启动失败时
- 服务间连接有问题时
- 需要优化容器配置时

### 询问模板
"我的Docker服务启动遇到问题：[具体错误信息]，请帮我诊断并修复配置文件。"

### Agent应该交付
- 修复的docker-compose.yml配置
- 容器配置优化建议
- 问题诊断和解决方案

## 成功标准（你能看到的结果）

- [ ] **所有容器正常运行**：`docker-compose ps`显示所有服务Up
- [ ] **数据库可连接**：能通过psql连接PostgreSQL
- [ ] **Redis可连接**：redis-cli ping返回PONG
- [ ] **前端页面加载**：localhost:3000显示React应用
- [ ] **后端API可访问**：localhost:8000/docs显示API文档
- [ ] **数据持久化工作**：重启容器后数据不丢失

## 技术背景信息

### Docker服务配置
- **PostgreSQL**: postgres:15镜像，端口5432，数据持久化
- **Redis**: redis:7-alpine镜像，端口6379，内存存储
- **前端**: React + Vite开发服务器，端口3000
- **后端**: FastAPI + Python，端口8000

### 资源要求
- Docker Desktop内存：至少4GB
- 磁盘空间：至少20GB
- CPU：建议2核以上

### 常见问题排查
如遇到问题，可向dev agent询问：
- 端口冲突：`lsof -i :端口号`
- 容器日志：`docker-compose logs 服务名`
- 网络问题：`docker network ls`
