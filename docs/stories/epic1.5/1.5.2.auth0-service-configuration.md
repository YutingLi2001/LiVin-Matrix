# Story 1.5.2: Auth0认证服务配置与测试

## Status
Draft

## Story
**作为** 系统部署者，
**我希望** 完成Auth0认证服务的配置和集成测试，
**以便** 为LiVin Matrix项目提供安全的用户认证和授权功能。

## Acceptance Criteria

1. **Auth0账号创建和基础配置完成**
   - Auth0免费账号注册并验证完成
   - 租户（tenant）创建并配置完成
   - 管理仪表板访问权限确认
   - 基础安全设置配置完成
   - 开发环境配置就绪

2. **Single Page Application (SPA)应用创建并配置**
   - 在Auth0 Dashboard中创建SPA应用
   - 应用设置正确配置（名称、描述、类型）
   - 允许的回调URL配置：`http://localhost:3000/callback`, `https://your-domain.github.io/callback`
   - 允许的登出URL和Web Origin配置
   - 应用密钥和客户端ID获取完成

3. **用户认证流程配置完成**
   - 邮箱/密码认证方式启用
   - 用户注册流程配置
   - 密码策略设置（强度要求）
   - 邮箱验证配置（可选）
   - 社交登录选项配置（如需要）

4. **API授权配置完成**
   - API资源创建并配置（API Identifier）
   - 权限范围（Scopes）定义
   - JWT令牌配置（RS256算法）
   - 令牌生存期设置
   - API权限分配给应用

5. **开发环境集成测试通过**
   - 本地前端应用可以成功跳转到Auth0登录页面
   - 用户注册和登录流程正常工作
   - JWT令牌正确生成和验证
   - 后端API能够验证Auth0 JWT令牌
   - 用户信息获取API正常工作

### Auth0配置要求
**来源**: [Source: docs/stories/1.3.auth0-user-authentication-integration.md#Auth0配置要求]

**应用配置规范**:
- 应用类型：Single Page Application
- 认证方式：Username-Password-Authentication
- JWT算法：RS256
- Audience：API标识符

**环境变量配置**:
```bash
# 前端环境变量 (.env)
VITE_AUTH0_DOMAIN=your-tenant.auth0.com
VITE_AUTH0_CLIENT_ID=your-client-id
VITE_AUTH0_AUDIENCE=https://api.livin-matrix.example.com
VITE_API_BASE_URL=http://localhost:8000

# 后端环境变量 (.env)
AUTH0_DOMAIN=your-tenant.auth0.com
AUTH0_AUDIENCE=https://api.livin-matrix.example.com
AUTH0_ALGORITHM=RS256
```

```bash
# 测试认证端点
curl -X POST "https://your-tenant.auth0.com/oauth/token" \
  -H "Content-Type: application/json" \
  -d '{"grant_type":"client_credentials","client_id":"your-client-id","client_secret":"your-client-secret","audience":"your-api-identifier"}'
```

**前端集成测试**:
```javascript
// 测试Auth0Provider配置
test('Auth0Provider properly configured', () => {
  expect(process.env.VITE_AUTH0_DOMAIN).toBeDefined();
  expect(process.env.VITE_AUTH0_CLIENT_ID).toBeDefined();

// 测试登录流程
test('Login redirects to Auth0', async () => {
  const { getByRole } = render(<LoginPage />);
  fireEvent.click(getByRole('button', { name: /login/i }));

});
```

**后端API测试**:
```python
# 测试JWT验证
```
