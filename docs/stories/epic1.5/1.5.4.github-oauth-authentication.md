# Story 1.5.4: GitHub OAuth认证系统集成

## Status
Ready

## 你的目标
配置GitHub OAuth认证系统，让用户能通过GitHub账号登录应用，并确保认证流程在前后端正常工作。

## 你需要做的关键操作

### 🔐 GitHub OAuth应用配置（你必须亲自完成）
- [ ] **创建GitHub OAuth App**
  1. 访问GitHub Settings > Developer settings > OAuth Apps
  2. 点击"New OAuth App"
  3. 配置应用信息：
     - Application name: `LiVin Matrix Authentication`
     - Homepage URL: `http://localhost:3000`
     - Authorization callback URL: `http://localhost:3000/auth/callback`
  4. 记录生成的Client ID和Client Secret

- [ ] **配置环境变量**
  ```bash
  # 在backend/.env中添加
  GITHUB_CLIENT_ID=你的Client ID
  GITHUB_CLIENT_SECRET=你的Client Secret
  
  # 在frontend/.env中添加
  VITE_GITHUB_CLIENT_ID=你的Client ID
  ```

### 🚀 启动认证系统（你亲自测试）
- [ ] **启动后端服务**
  ```bash
  cd backend
  python -m uvicorn app.main:app --reload
  ```

- [ ] **启动前端服务**
  ```bash
  cd frontend
  npm run dev
  ```

### 🧪 认证流程测试（你亲自验证）
- [ ] **测试GitHub登录流程**
  1. 访问 http://localhost:3000
  2. 点击"GitHub登录"按钮
  3. 验证跳转到GitHub授权页面
  4. 同意授权后验证回跳到应用
  5. 确认用户信息正确显示

- [ ] **测试API保护功能**
  ```bash
  # 测试无认证访问（应该失败）
  curl http://localhost:8000/api/v1/auth/profile
  
  # 登录后从浏览器获取JWT令牌，测试认证访问
  curl -H "Authorization: Bearer YOUR_TOKEN" http://localhost:8000/api/v1/auth/profile
  ```

- [ ] **测试登出功能**
  - 在前端点击登出按钮
  - 验证重定向到登录页面
  - 确认无法再访问受保护的页面

## 技术背景信息

### 认证架构
- **前端**: React + GitHub OAuth登录按钮
- **后端**: FastAPI + JWT令牌验证
- **存储**: PostgreSQL用户表 + Redis令牌黑名单

### 环境变量配置
```bash
# 后端必需
GITHUB_CLIENT_ID=你的Client ID
GITHUB_CLIENT_SECRET=你的Client Secret
JWT_SECRET_KEY=随机密钥字符串

# 前端必需
VITE_GITHUB_CLIENT_ID=你的Client ID
VITE_API_BASE_URL=http://localhost:8000
```

### 常见问题排查
如遇到问题，可向dev agent询问：

- JWT验证失败：检查密钥配置
- 用户信息获取失败：检查API端点实现
