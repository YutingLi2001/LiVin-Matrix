# Story 1.5.4: AWS基础设施部署执行

## Status
Draft

## Story
**作为** 系统部署者，
**我希望** 执行AWS基础设施的自动化部署，
**以便** 在云环境中建立完整的LiVin Matrix生产基础设施。

## Acceptance Criteria

1. **VPC和网络基础设施创建完成**
   - 专用VPC创建成功，网络CIDR配置正确
   - 公有子网和私有子网创建完成
   - Internet Gateway和NAT Gateway配置正确
   - 路由表和安全组规则创建完成
   - VPC Flow Logs启用并正常记录

2. **EKS Kubernetes集群部署成功**
   - EKS控制平面创建完成，状态为Active
   - Worker节点组创建成功（2个t3.micro节点）
   - kubectl连接到集群正常工作
   - AWS Load Balancer Controller安装完成
   - 集群DNS和网络插件正常运行

3. **RDS PostgreSQL数据库部署完成**
   - RDS实例创建成功（db.t3.micro免费层）
   - 数据库安全组配置正确，只允许EKS访问
   - AWS Secrets Manager中存储数据库凭据
   - 数据库参数组和备份配置完成
   - 数据库连接测试通过

4. **Application Load Balancer配置完成**
   - ALB创建成功，监听器配置正确
   - SSL证书通过AWS Certificate Manager创建
   - 健康检查和路由规则配置完成
   - Target Groups创建并关联EKS服务
   - 域名DNS记录指向ALB

5. **监控和告警系统配置完成**
   - CloudWatch监控仪表板创建
   - 费用预算告警配置（月预算<$5）
   - 基础设施监控指标收集正常
   - SNS通知主题创建并测试
   - 所有资源标签正确应用

### 安全配置策略
**来源**: [Source: deploy/aws/security-groups.yaml]

**安全组配置**:
- **ALB安全组**: 允许HTTP(80)和HTTPS(443)入站
- **EKS节点安全组**: 允许集群通信和ALB访问
- **RDS安全组**: 仅允许EKS节点访问PostgreSQL(5432)
- **管理安全组**: 受限的SSH访问（仅在需要时启用）

**IAM权限策略**:
- EKS集群服务角色
- EKS节点组实例角色
- AWS Load Balancer Controller角色
- RDS监控角色

### 部署脚本执行顺序
**来源**: [Source: deploy/scripts/aws-setup.sh]

**标准部署流程**:
1. **前置检查**: 验证工具、权限、免费层状态
2. **VPC创建**: 网络基础设施和安全组
3. **EKS部署**: 集群创建和节点组配置
4. **RDS创建**: 数据库实例和参数配置
5. **ALB配置**: 负载均衡器和SSL证书
6. **应用部署**: Kubernetes资源和应用容器
7. **监控配置**: CloudWatch仪表板和告警
8. **验证测试**: 完整系统功能验证

### 错误处理和回滚策略
**来源**: [Source: deploy/ROLLBACK_GUIDE.md]

**常见错误场景**:
- EKS节点组创建失败（通常是权限或配额问题）
- RDS实例启动超时（网络或参数组问题）
- ALB Target Group健康检查失败
- SSL证书验证超时

**回滚策略**:
```bash
# 完整环境回滚
./deploy/scripts/aws-setup.sh rollback

# 部分资源回滚
aws eks delete-cluster --name livin-matrix-cluster
aws rds delete-db-instance --db-instance-identifier livin-matrix-db
```

### 测试框架和标准

**AWS资源验证测试**:
```bash
# VPC和网络验证
aws ec2 describe-vpcs --filters "Name=tag:Name,Values=livin-matrix-vpc"
aws ec2 describe-subnets --filters "Name=vpc-id,Values=vpc-xxxxxx"

# EKS集群验证
aws eks describe-cluster --name livin-matrix-cluster
kubectl get nodes
kubectl get pods --all-namespaces

# RDS数据库验证
aws rds describe-db-instances --db-instance-identifier livin-matrix-db
psql -h <rds-endpoint> -U postgres -d livin_matrix -c "SELECT 1;"

# ALB验证
aws elbv2 describe-load-balancers
curl -f https://your-domain.com/health
```

**应用功能验证测试**:
```bash
# 后端API健康检查
curl -f https://api.livin-matrix.example.com/health

# 数据库连接测试
curl -f https://api.livin-matrix.example.com/api/v1/health/db

# 认证系统测试
curl -X POST https://api.livin-matrix.example.com/api/v1/auth/test
```

**监控和告警验证**:
```bash
# CloudWatch指标检查
aws cloudwatch get-metric-statistics \
  --namespace AWS/EKS \
  --metric-name cluster.status \
  --dimensions Name=ClusterName,Value=livin-matrix-cluster

# 预算告警测试
aws budgets describe-budgets --account-id <account-id>
```
