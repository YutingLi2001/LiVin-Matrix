## 技术背景信息

### 数据库结构变化
```sql
-- 用户表扩展字段
ALTER TABLE users ADD COLUMN password_hash VARCHAR(255) NULL;
ALTER TABLE users ADD COLUMN email_verified BOOLEAN DEFAULT FALSE;
ALTER TABLE users ADD COLUMN verification_token VARCHAR(255) NULL;
ALTER TABLE users ADD COLUMN password_reset_token VARCHAR(255) NULL;
ALTER TABLE users ADD COLUMN password_reset_expires TIMESTAMP NULL;
ALTER TABLE users ADD COLUMN auth_provider VARCHAR(50) DEFAULT 'github';

-- 使GitHub字段可选
ALTER TABLE users ALTER COLUMN github_user_id DROP NOT NULL;
ALTER TABLE users ALTER COLUMN github_username DROP NOT NULL;
```

### 认证架构扩展
```
原架构: 前端 → GitHub OAuth → JWT令牌
新架构: 前端 → [GitHub OAuth | 邮箱密码] → JWT令牌
```

### Resend邮件发送架构
```
FastAPI应用 → Resend Python SDK → Resend HTTP API → 用户邮箱
```

**Resend集成优势**:
- **超简单API**: 只需3行代码发送邮件
- **高送达率**: 现代化邮件基础设施
- **实时监控**: 控制台可查看发送状态
- **免费额度**: 3000封/月，足够小项目使用

### 安全考虑
- **密码哈希**: 使用bcrypt加盐哈希存储
- **邮箱验证**: 防止垃圾注册和邮箱劫持
- **令牌安全**: 验证令牌设置过期时间
- **频率限制**: 防止邮件发送滥用
- **SQL注入防护**: 使用参数化查询

### 用户体验设计
```

```

### Python邮件发送服务示例
```python
# backend/app/services/email_service.py
import resend
from app.core.config import settings

class EmailService:
    def __init__(self):
        resend.api_key = settings.RESEND_API_KEY
    
    async def send_verification_email(self, to_email: str, token: str) -> bool:
        """发送邮箱验证邮件"""
        try:
            email = resend.Emails.send({
                "from": settings.EMAIL_FROM_ADDRESS,
                "to": to_email,
                "subject": "验证您的LiVin Matrix账户",
                "html": f"""
                <div style="font-family: Arial, sans-serif; max-width: 600px; margin: 0 auto;">
                    <h2>欢迎加入LiVin Matrix!</h2>
                    <p>请点击下面的按钮验证您的邮箱地址：</p>
                    <a href="http://localhost:3000/verify-email?token={token}" 
                       style="background-color: #007bff; color: white; padding: 12px 24px; 
                              text-decoration: none; border-radius: 6px; display: inline-block;">
                        验证邮箱
                    </a>
                    <p>如果按钮无法点击，请复制以下链接到浏览器：</p>
                    <p>http://localhost:3000/verify-email?token={token}</p>
                    <p>此链接将在24小时后过期。</p>
                </div>
                """
            })
            return True
        except Exception as e:
            print(f"Email send failed: {e}")
            return False
```

## 重要提醒

⚠️ **Resend服务配置注意事项**:
