### 🏗️ 极简AWS部署（你亲自执行）

#### 步骤1: 启动EC2实例
```bash
# 1. 创建EC2实例
aws ec2 run-instances \
  --image-id ami-0c02fb55956c7d316 \
  --instance-type t3.small \
  --key-name your-key-pair \
  --security-group-ids sg-12345678 \
  --subnet-id subnet-12345678 \
  --tag-specifications 'ResourceType=instance,Tags=[{Key=Name,Value=livin-matrix-prod}]'

# 2. 分配Elastic IP
aws ec2 allocate-address --domain vpc
aws ec2 associate-address --instance-id i-1234567890abcdef0 --allocation-id eipalloc-12345678
```

#### 步骤2: 配置生产环境
```bash
# SSH到EC2实例
ssh -i your-key.pem ubuntu@your-elastic-ip

# 安装Docker和Docker Compose
sudo apt update
sudo apt install -y docker.io docker-compose-plugin
sudo usermod -aG docker ubuntu

# 克隆项目
git clone https://github.com/your-username/LiVin-Matrix.git
cd LiVin-Matrix
```

#### 步骤3: 部署应用
```bash
# 配置生产环境变量
cp .env.example .env.production
# 编辑生产配置：数据库密码、GitHub OAuth等

# 使用生产Docker Compose配置
docker compose -f docker-compose.yml -f docker-compose.production.yml up -d

# 验证部署
docker compose ps
curl http://localhost:8000/health
```

### 🔗 生产配置优化（你亲自验证）

#### 配置Nginx SSL终止
```bash
# 安装Certbot获取SSL证书
sudo apt install -y certbot nginx
sudo certbot --nginx -d your-domain.com

# 配置Nginx代理到Docker应用
sudo cp deploy/nginx/production.conf /etc/nginx/sites-available/livin-matrix
sudo ln -s /etc/nginx/sites-available/livin-matrix /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

#### 可选: 使用RDS替代容器数据库
```bash
# 如果选择RDS，创建PostgreSQL实例
aws rds create-db-instance \
  --db-instance-identifier livin-matrix-db \
  --db-instance-class db.t3.micro \
  --engine postgres \
  --allocated-storage 20 \
  --master-username livin_admin \
  --master-user-password your-secure-password

# 更新.env.production中的DATABASE_URL
DATABASE_URL=postgresql://livin_admin:password@your-rds-endpoint:5432/livin_matrix
```
