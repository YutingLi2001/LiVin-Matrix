[Source: Story 1.5.4.1 - 实施总结]

```

├── docker-compose.yml              # 基础服务定义
├── docker-compose.dev.yml          # 开发环境配置
├── docker-compose.secrets.yml      # 生产环境Docker Secrets配置
```

#### 环境变量映射
需要确保的关键环境变量：
- `SECRET_KEY`: FastAPI应用密钥

- `GITHUB_CLIENT_ID` / `GITHUB_CLIENT_SECRET`: GitHub OAuth配置
- `JWT_SECRET_KEY`: JWT令牌签名密钥
- `REDIS_URL`: Redis缓存连接
