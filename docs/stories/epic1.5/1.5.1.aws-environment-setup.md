## Story
**作为** 系统部署者，
**我希望** 完成AWS账号创建和基础环境配置，

## Acceptance Criteria

1. **AWS免费账号创建并验证完成**
   - AWS账号注册成功，邮箱验证完成
   - 信用卡验证通过，账号状态为Active
   - 免费层资格确认激活
   - 账号安全设置配置（MFA启用）
   - 计费告警配置（月预算<$5美元）

2. **AWS CLI工具安装并配置完成**
   - AWS CLI v2安装到本地开发环境
   - AWS凭据配置完成（Access Key/Secret Key）
   - 权限验证通过，可以访问必要的AWS服务
   - 区域配置为us-east-1（免费层友好）
   - CLI配置文件正确设置

3. **IAM权限和安全策略配置**
   - 创建专用IAM用户用于部署操作
   - 配置最小权限策略（EKS、RDS、ALB、CloudWatch）
   - 启用CloudTrail审计日志记录
   - 配置密码策略和访问密钥轮换
   - 创建部署用的服务角色

4. **免费层资源监控和告警设置**
   - CloudWatch费用告警配置
   - 免费层使用量监控仪表板
   - 资源超出阈值时的自动通知
   - 月度成本报告自动发送设置
   - 资源清理提醒配置

5. **基础网络环境准备验证**
   - 默认VPC和子网状态检查
   - 网络连接性测试
   - DNS解析验证
   - 安全组规则基础验证
   - 互联网网关连接确认

### AWS免费层资源限制
**来源**: [Source: docs/architecture/7-部署架构和基础设施-deployment-infrastructure-architecture.md#7.1]

**关键免费层限制**:
- EKS集群: 1个集群/月（控制平面免费）
- EC2 t3.micro: 750小时/月（约1个月全时运行）
- RDS PostgreSQL: 20GB存储 + 750小时数据库时间
- S3存储: 5GB标准存储
- 数据传输: 15GB出站/月

### 必需工具和权限
**来源**: [Source: deploy/scripts/aws-setup.sh#prerequisites]

**必需的本地工具**:
- AWS CLI v2
- kubectl (Kubernetes命令行工具)
- eksctl (EKS集群管理工具)
- jq (JSON处理工具)

**必需的AWS权限**:
- EC2权限（创建VPC、安全组、实例）
- EKS权限（创建集群、节点组）
- RDS权限（创建数据库实例、参数组）
- ALB权限（创建负载均衡器）
- IAM权限（创建角色、策略）
- CloudWatch权限（创建告警、仪表板）

### 安全配置最佳实践
**来源**: [Source: deploy/aws/security-groups.yaml, docs/architecture/8-安全和性能考虑-security-and-performance-considerations.md]

**IAM安全策略**:
- 使用最小权限原则
- 启用多因素认证（MFA）
- 定期轮换访问密钥
- 使用IAM角色而非长期凭据

**网络安全策略**:
- 默认拒绝所有入站流量
- 仅开放必要端口
- 使用私有子网部署敏感资源
- 启用VPC Flow Logs进行审计

### 成本控制策略
**来源**: [Source: docs/stories/1.6.aws-infrastructure-deployment.md#监控和成本控制]

**预算控制措施**:
- 月度预算设置为$5美元
- 免费层使用量监控
- 资源自动清理脚本
- 实时成本跟踪和告警

**资源优化**:
- 使用t3.micro实例类型
- 启用自动扩缩容
- 合理设置备份保留期
- 监控未使用资源
