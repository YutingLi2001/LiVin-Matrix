## 技术背景信息

### API端点架构
- **认证端点**: `/api/v1/auth/*` (登录、登出、用户信息)
- **数据端点**: `/api/v1/records/*` (健康数据CRUD)
- **健康检查**: `/api/v1/health` (系统状态)

### 6维度数据模型
- **睡眠**: 睡眠时间、质量评分
- **饮食**: 卡路里、蛋白质等营养素
- **运动**: 锻炼时长、步数
- **情绪**: 心情、压力、能量水平
- **工作效率**: 深度工作时间、专注度
- **社交**: 社交互动频率、满意度

### 常见问题排查
如遇到问题，可向dev agent询问：
- API响应异常：检查错误日志和状态码
- 前后端数据不一致：检查数据格式和验证逻辑
- 认证问题：检查JWT令牌和中间件配置
