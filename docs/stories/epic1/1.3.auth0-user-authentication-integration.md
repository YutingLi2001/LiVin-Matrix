## Story (历史记录)
**作为** 应用用户，
**我希望** 能够安全地注册、登录和管理我的账户，
**以便** 我能够安全地访问我的个人数据并保护我的隐私。

**应用配置**:

- 回调URL：`http://localhost:3000`, `https://your-domain.github.io`
- 允许的Web Origins：同回调URL

- 算法：RS256
