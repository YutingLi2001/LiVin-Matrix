# Story 1.1: 项目基础架构搭建

## Status
Done

## Story
**As a** 开发团队，
**I want** 建立标准化的项目结构和开发环境，
**so that** 可以高效协作开发，快速上手项目开发。

## Acceptance Criteria

1. **Monorepo项目结构创建完成**
   - 创建根目录结构：`frontend/`, `backend/`, `database/`, `deploy/`, `docs/`
   - 在根目录创建 `package.json`，配置工作区管理
   - 每个子目录包含相应的 `README.md` 说明文件
   - `.gitignore` 文件涵盖前后端常见的忽略文件

2. **Docker和Docker Compose配置文件就位**
   - 根目录创建 `docker-compose.yml`，包含所有服务配置
   - 前端Dockerfile配置：多阶段构建，优化镜像大小
   - 后端Dockerfile配置：Python环境，依赖管理
   - PostgreSQL服务配置：数据持久化，环境变量
   - 开发环境可以通过 `docker-compose up` 一键启动

3. **前端React+TypeScript项目初始化**
   - 使用 `create-react-app` 创建TypeScript项目
   - 安装和配置Tailwind CSS，包含深色主题配置
   - 配置React Router，建立基础路由结构
   - 安装必要依赖：`@types/react`, `@types/node`
   - ESLint和Prettier配置，保证代码一致性

4. **后端FastAPI项目初始化**
   - 创建基础FastAPI项目结构：`app/`, `tests/`, `requirements.txt`
   - 配置虚拟环境和依赖管理（`requirements.txt`）
   - 基础API结构：路由、中间件、配置文件
   - 开发服务器配置：热重载，调试模式
   - 集成pytest测试框架，基础测试用例

5. **项目README文档完整**
   - 项目简介和技术栈说明
   - 环境要求：Node.js版本、Python版本、Docker版本
   - 本地开发环境搭建步骤（详细命令）
   - 常用开发命令说明（启动、测试、构建）
   - 贡献指南和代码规范说明

## Dev Notes

### 技术栈配置
**来源**: [Source: architecture.md#3.1-前端技术栈, #3.2-后端技术栈]

**前端技术栈**:
- React 18+ (现代前端标准，生态成熟)
- TypeScript (类型安全，提升开发效率)
- Tailwind CSS (快速开发，高度可定制)
- React Router (标准路由解决方案)
- Lucide React (简洁稳定的图标库)

**后端技术栈**:
- FastAPI (现代Python web框架，自动API文档)
- SQLAlchemy (成熟的ORM，支持数据迁移)
- Pydantic (类型安全，自动验证)
- pytest (测试框架)

### 项目结构要求
**来源**: [Source: architecture.md#6.1-React组件架构设计]

**前端目录结构**:
```
frontend/src/
├── components/           # 可复用组件库
│   ├── ui/              # 基础UI组件
│   ├── forms/           # 表单相关组件
│   ├── matrix/          # 矩阵相关组件
│   └── layout/          # 布局组件
├── pages/               # 页面级组件
├── hooks/               # 自定义React Hooks
├── contexts/            # React Context状态管理
└── utils/               # 工具函数
```

**根目录结构要求**:
```
livin-matrix/
├── frontend/            # React应用
├── backend/             # FastAPI应用
├── database/            # 数据库相关
├── deploy/              # 部署配置
├── docs/                # 项目文档
├── docker-compose.yml   # 开发环境
├── package.json         # 根package.json
└── README.md
```

### 基础设施配置
**来源**: [Source: architecture.md#3.3-基础设施技术栈]

**容器化配置**:
- Docker + Docker Compose (开发环境一致性)
- 多阶段构建优化镜像大小
- 环境变量管理配置，支持开发/生产环境切换
- 数据库数据持久化配置

### 开发环境要求
**来源**: [Source: docs/ai-implementation-guide/01-project-setup.md]

**版本要求**:
- Node.js 18+
- Python 3.9+
- Docker 20.x+

**必需依赖包**:
- 前端: `@types/react`, `@types/react-dom`, `tailwindcss`, `react-router-dom`
- 后端: `fastapi[all]`, `uvicorn[standard]`, `sqlalchemy`, `pydantic`, `pytest`

### Tailwind配置要求
**来源**: [Source: docs/frontend-spec.md#1.2-视觉标识系统]

**赛博朋克配色方案**:
- 主色调: `--primary-500: #8b5cf6` (Obsidian紫)
- 背景: `--bg-primary: #000000` (纯黑主背景)
- 文本: `--text-primary: #ffffff` (纯白主要文本)
- 效果: 霓虹发光、玻璃质感、矩阵风格

### 路由结构要求
**来源**: [Source: epic1-story1-项目基础架构搭建.md#技术实现要点]

**基础路由配置**:
- `/login` - 用户登录页面
- `/dashboard` - 主仪表盘
- `/data-entry` - 数据录入页面

### 测试标准
**测试文件位置**:
- 前端: `frontend/src/__tests__/` 或组件同级 `*.test.tsx`
- 后端: `backend/tests/`

**测试框架**:
- 前端: React Testing Library + Jest (内置于create-react-app)
- 后端: pytest + pytest-asyncio

**测试要求**:
- 每个组件/模块至少有一个基础测试用例
- 测试Docker环境是否能正常启动
- 测试API端点的基础响应
