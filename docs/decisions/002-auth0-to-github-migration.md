# ADR-002: Auth0迁移至GitHub OAuth + Resend

## 状态
已实施 - 2025-08-02

## 背景
项目最初采用Auth0作为用户认证和邮件服务提供商，但Auth0每月$35的费用超出了项目预算限制。为了实现零成本运营目标，需要找到免费的替代方案。

## 决策
使用两个免费服务替换Auth0：

- **GitHub OAuth**: 免费的GitHub账号登录认证
- **Resend**: 免费的邮件发送服务（每月100封免费）
- **FastAPI JWT**: 后端自建 Token管理系统
- **PostgreSQL**: 用户数据存储

## 结果
- **成本降低**: 从每月$35降低到$0，实现零成本运营目标
- **功能保持**: GitHub OAuth提供稳定的用户认证，Resend提供可靠的邮件服务
- **开发效率**: 免费服务减少了费用管理和预算担忧
- **技术整合**: 两个免费服务的组合完全替代了Auth0的功能
